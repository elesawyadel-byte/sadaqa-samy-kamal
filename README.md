# صدقة جارية على روح سامي كمال عبده مصطفي

نسخة Website كاملة بنفس تطوير مشروع صدقة الحاج فتحي العيسوي، ومخصصة للمرحوم سامي كمال عبده مصطفي.

الموقع يشمل القرآن، الختمة والورد، الأذكار، الأدعية، الأحاديث، المبشرين بالجنة، الأنبياء في القرآن، الموسوعة الإسلامية، الحكم والمواعظ، الرقية، أسماء الله الحسنى، أعمال اليوم، سؤال اليوم، اختبر معلوماتك، ماذا أدعو؟، الأهداف اليومية، المفضلة، السبحة، مواقيت الصلاة والقبلة، البحث الشامل والوضع النهاري والليلي ووضع كبار السن.

هذه النسخة Website فقط، بدون APK أو PWA أو Service Worker أو أذان تلقائي أو تنبيهات صلاة.

تم تصحيح الحديث إلى:
«رغم أنفه، ثم رغم أنفه، ثم رغم أنفه... من أدرك والديه عند الكبر أحدهما أو كليهما ثم لم يدخل الجنة.»
صحيح مسلم 2551.
